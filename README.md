## About This Repository

This repository supports an eLearning experience aligned to Microsoft's
official **GH-900T00-A: GitHub Foundations** course. It is designed to move
learners from GitHub concepts to confident, collaborative practice through
short explanations, guided activities, and practical checkpoints.

The course is intended for learners who want to understand GitHub's fundamental
features and learn the GitHub flow, including repositories, commits, branches,
and pull requests. It also introduces the collaborative features used to
discuss work, track changes, and stay informed.

## Learning Objectives

By the end of this eLearning experience, learners should be able to:

- Explain what GitHub is and describe its value as a collaborative platform.
- Navigate the core parts of a GitHub repository and identify where project
	content, history, and collaboration happen.
- Describe how commits record changes and how branches support parallel work.
- Follow the GitHub flow from a proposed change through review and merge.
- Distinguish the purposes of issues, discussions, and pull requests.
- Participate in project collaboration using clear, useful communication.
- Manage GitHub notifications and subscriptions so important activity remains
	visible and manageable.
- Apply foundational GitHub practices in a small, repeatable workflow.

## Learning Modules

| Module | Focus | Learner outcome |
| --- | --- | --- |
| **01 - GitHub fundamentals** | GitHub as a collaborative platform | Describe GitHub's purpose, core concepts, and the problems it helps teams solve. |
| **02 - Repository management** | Repositories, files, history, and access | Locate key repository areas and explain how project work is organized. |
| **03 - Commits and branches** | Change history and parallel work | Explain how commits capture changes and why branches isolate work. |
| **04 - GitHub flow** | Branch, change, review, and merge | Trace a change through the GitHub flow and identify each decision point. |
| **05 - Pull requests and merging** | Review and integration | Describe how pull requests support feedback, discussion, and merging. |
| **06 - Issues and discussions** | Planning and collaboration | Choose the right collaboration space for a task, question, idea, or conversation. |
| **07 - Notifications and subscriptions** | Staying informed | Configure notification and subscription habits that support effective teamwork. |
| **08 - Capstone workflow** | Integrated practice | Complete a small end-to-end contribution using foundational GitHub practices. |

> **Scope note:** The module sequence above organizes the official GH-900
> subject areas into an eLearning path. Microsoft Learn remains the source of
> truth for current product behavior, terminology, and certification details.

## Practice and Assessment

Learning activities will reinforce the concepts through:

- **Concept checks** that test terminology and workflow decisions.
- **Guided repository tours** that connect concepts to the GitHub interface.
- **Scenario exercises** for choosing between commits, branches, issues,
	discussions, and pull requests.
- **Capstone practice** that brings the GitHub flow together in one small
	contribution workflow.
- **Reflection prompts** that help learners identify habits they can apply to
	their own projects.

## Intended Audience

This repository is intended for students, new GitHub users, and contributors
who need a structured introduction to GitHub's foundational features and best
practices. No advanced GitHub experience is assumed.
